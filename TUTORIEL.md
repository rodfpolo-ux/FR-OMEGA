# 🚀 FR-OMEGA - TUTORIEL

## 📌 C’est quoi ?

FR-OMEGA est un protocole de commandes en français qui permet de contrôler une IA avec des instructions simples.

---

## ⚙️ Installation

1. Copie le contenu du fichier FR-OMEGA
2. Colle-le dans le "System Prompt" de ton IA
3. Sauvegarde
4. C’est prêt 👍

---

## 💬 Comment utiliser

Tu écris une commande comme ça :

/A @Windows Defender %EXPERT

---

## 📌 Exemples

🔎 Recherche :
/R @War Thunder

🧠 Analyse :
/A @RTX 5090 %EXPERT

⚖️ Comparaison :
/CP @uBlock Origin & Malwarebytes %DETAILLE

---

## 🧠 Explication rapide

- /A = Analyse
- /R = Recherche
- /CP = Comparaison
- @ = sujet
- % = niveau

---

## ❌ Erreurs possibles

ERREUR:COMMANDE → commande inconnue  
ERREUR:SUJET → sujet manquant  
ERREUR:DONNEE → information manquante

---

## 🚀 Fin

Tu peux maintenant utiliser FR-OMEGA pour contrôler ton IA.
